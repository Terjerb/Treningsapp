# Treningsapp V1.0

Mobiltilpasset treningsapp for styrke, 4 x 5 x 45/15-intervaller og langtur i sone 2.

## Publisering på GitHub Pages

1. Last opp alle filene i denne mappen til roten av GitHub-repositoryet.
2. Gå til Settings > Pages.
3. Velg Deploy from a branch, `main` og `/(root)`.
4. Åpne adressen GitHub oppgir.

## Lagring

Treningsdata lagres lokalt i nettleseren. Bruk eksportfunksjonen i appen for sikkerhetskopi.
